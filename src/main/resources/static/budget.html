Остаток после расходов

План использует весь остаток месяца на долги. Если нужен резерв, добавь его в расходы. Доплата идёт туда, где проценты за период выше относительно остатка долга. Платежи из прошлых месяцев сдвигаются на текущий месяц, без расчёта штрафов. Свободные деньги не переносятся между месяцами.
